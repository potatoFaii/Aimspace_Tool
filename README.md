# AimSpace Tool for Autodesk Maya

![UI](https://github.com/user-attachments/assets/d54e7189-923c-497e-b5c1-cc98952021c1)

## Overview
**AimSpace** is a personal Maya animation utility inspired by the workflow and concepts shared by  
**Richard Lico** via [Animation Sherpa](https://www.animationsherpa.com/).

This tool is designed to assist animators in **analyzing and refining rotational motion**, particularly for hand-driven props such as swords, by improving motion clarity and control through locator-based workflows.

> ⚠️ This script is intended for **personal and educational use only**.

---

## Features
- Helps analyze animation smoothness using **Motion Trails**
- Provides clearer tracking of object rotation and movement
- Designed for animator-driven workflows
- Lightweight and simple to integrate into existing scenes
- Intended to complement experience-based animation judgment

---

## Installation
1. Open **Autodesk Maya**
2. Drag and drop `AimSpace_Install.mel` into the Maya viewport
3. A shelf icon will be created automatically
4. Click the icon to launch the tool

---

## Usage
1. Create a **locator** aligned to the correct **rotation axis**  
   *(e.g. aligned with a sword’s direction)*
2. Bake the hand animation keys onto the locator
3. Use the locator to control the hand animation
4. Ensure the rotation axis is properly aligned **before running the script**
5. Use **Motion Trails** to visually evaluate animation smoothness

*(Recommended for weapon animation, rotational cleanup, and motion analysis.)*

---

## Workflow Notes
- Proper axis alignment is critical for accurate results
- This tool is most effective when used with animation fundamentals in mind
- For advanced usage, consult experienced animators familiar with this workflow
